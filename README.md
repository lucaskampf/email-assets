# email-assets

Öffentliches Hosting der Logos für alle E-Mail-Signaturen (WhiteRoot UG/FlexCo, Trockenbau Kampf, WinWinConnector, Kampf Holding, Kampfs Dinner, Lucas Kampf privat).

Ausgeliefert über GitHub Pages:

`https://lucaskampf.github.io/email-assets/logos/<datei>.png`

Kopien liegen weiterhin im Shopify-CDN (Inhalte → Dateien), die neuen Signaturen nutzen aber nur noch diese URLs.

## Regeln

- **Dateinamen nie ändern oder löschen** – jede verschickte Mail verweist dauerhaft auf diese URLs. Ein neues Logo bekommt einen neuen Dateinamen (z. B. `…-v2.png`).
- Repo muss **öffentlich** bleiben, sonst laden die Bilder nicht.
- PNG in doppelter Auflösung (@2x), im HTML auf die halbe Breite skaliert.
