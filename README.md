# email-assets

Legacy-Hosting der Logos für E-Mail-Signaturen. Bereits verschickte Mails verweisen dauerhaft auf die Dateien in `logos/`.

## Regeln

- **Dateien nie umbenennen oder löschen.**
- Das Repo muss **öffentlich** bleiben, sonst laden die Bilder in alten Mails nicht mehr.

Neue Signaturen nutzen einen anderen Host. Hier kommen keine neuen Logos mehr hinzu.
